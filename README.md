# 半导体止跌监测

最简单的用法：在 Mac Finder 中双击 [一键更新止跌监测.command](一键更新止跌监测.command)。它会自动取最近一个**已经完整收盘**的美股交易日、下载 SOXX/LRCX/MU/SMH/SPY 日线、更新历史统计，并打开一页中文状态表。首次打开若 macOS 提示来源不明，可右键文件选择「打开」。

如果是从 GitHub 下载或克隆后使用，网页上传可能使 `.command` 失去可执行权限；首次在该目录的 Terminal 运行 `chmod +x "一键更新止跌监测.command"`，此后即可双击。当前电脑上的原文件已具备可执行权限，不用重复操作。

运行后会在本机生成 `backtest_output/latest_status.html`，文字版为 `backtest_output/latest_status.md`。状态分三种：

- `止跌候选已触发`：数据日期正好是目标收盘日，且规则满足；若按规则交易，最早下一交易日开盘执行。
- `未触发`：数据日期正确，但规则不足；页面直接列出缺失的关键条件。
- `数据待更新`：行情尚未覆盖目标日期，可能是休市或数据延迟。不能用旧数据判断当日信号。

美东时间 17:00 后才允许读取当日完整日线，比常规 16:00 收盘晚一小时。周末自动回退到上一个工作日；美国节假日可能显示「数据待更新」，请等待数据源更新。页面上的状态会在**再次双击运行后**更新；仅打开旧 HTML 文件不会自动刷新。

本机的 Codex 计划任务已另行设置为香港时间周二至周六早上 8:00 检查；计划任务不包含在这个 GitHub 仓库中，也不会随克隆自动启用。它需要电脑开机、联网且 Codex 桌面应用运行。脚本本身不会下单。

## 终端运行与自定义

需要 Python 3.10 或更新版本。在本目录的 Terminal 里运行下面一行即可；不传日期时自动使用最近五年和最近完整收盘日：

```bash
python3 semiconductor_bottoming_backtest.py
```

指定时间范围、交易成本或输出目录：

```bash
python3 semiconductor_bottoming_backtest.py --start 2021-10-23 --end 2026-10-23 --cost-bps-one-way 5 --out backtest_output
```

默认使用 Yahoo Finance 的公开日线，不需要安装 Python 包。Mac 上优先调用系统 `curl` 下载并验证 HTTPS 证书；Python 环境缺少证书时也无需手动使用不安全选项。若数据源临时限流，稍后再试。失败时终端会显示错误，旧状态文件保留旧的检查时间。

若要以 IBKR 导出为准，将 `SOXX.csv`、`LRCX.csv`、`MU.csv`、`SMH.csv`、`SPY.csv` 放在同一目录，每个文件必须有 `Date,Open,High,Low,Close,Volume` 列，再运行：

```bash
python3 semiconductor_bottoming_backtest.py --csv-dir /你的/IBKR导出目录
```

## 判据与回测口径

T 日收盘后才判定，T+1 开盘模拟买入。必须同时满足：T 日最低价相对之前 20 日最高价回撤至少 6%；T 日收盘高于前一日最高价或高于当日 5 日均线；以下四项至少有三项：成交量达到前 20 日中位数、真实波幅不超过 1.75 倍 ATR(14)、5 日相对 SPY 收益不差于 -4%、SPY 高于其 20 日均线或不创前 5 日收盘新低。

每个标的的 `*_report.md` 给出 5/20/60 日胜率、均值、分位数及最大不利波动；`*_signals.csv` 是逐日判断，`*_events.csv` 是回测事件。主事件至少间隔 60 个交易日，避免 60 日持有期重叠；样本外按时间从研究区间后 40% 独立去重。基准包括单日下跌至少 5% 后次日开盘买入、每 60 日无条件定期买入，以及整段持有收益。短期收益默认买卖各扣 5 bp 成本，可改 `--cost-bps-one-way`。不同策略的触发日期和市场环境不完全匹配，表格不能证明规则有稳定优势。Yahoo 日线价格可能经过拆股调整，分红与税未计入；实际下单前应以券商报价核对。

这些是历史研究和规则提醒。半导体 ETF 与个股仓位高度相关；若要执行补仓，应先用可承受亏损和失效价位限制仓位，避免把全部现金压在一次信号上。
